배드민턴 온라인 1대1 시제품

1. Node.js (LTS) 설치
2. 이 폴더에서 터미널을 열고 npm install 실행
3. npm start 실행
4. 같은 컴퓨터에서 http://localhost:3000 접속
5. 첫 플레이어는 '방 만들기'를 누르고 방 코드 공유
6. 두 번째 플레이어는 같은 서버 주소에 접속하고 방 코드 입력
7. 각자 '경기 시작' 버튼을 누르면 플레이 가능

서로 다른 인터넷망에서 접속하려면 서버를 외부에 배포하거나 포트 3000을 공개해야 합니다.
공개 인터넷에는 HTTPS/WSS를 제공하는 호스팅을 권장합니다.

이 버전은 온라인 멀티플레이어 기능을 검증하기 위한 별도 시제품입니다.
기존 AI 버전의 모든 샷 애니메이션, 고급 충돌, 서비스 규칙을 완전히 이식한 버전은 아닙니다.
서버가 공의 물리, 점수, 타격 유효성을 판정하며 두 플레이어의 위치와 타격을 동기화합니다.
